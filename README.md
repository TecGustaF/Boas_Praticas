# Boas_Praticas
Projeto em html para ser uma pagina web de um pet shop 
Este é um site desenvolvido em HTML, CSS e JavaScript para o Petshop do Gustavao. O site tem como objetivo apresentar os serviços do pet shop, informações sobre a equipe, clientes satisfeitos e meios de contato.

Página Inicial: Apresentação do pet shop e seus serviços.
Equipe: Informações sobre os profissionais que trabalham no pet shop.
Clientes: Depoimentos e fotos de clientes satisfeitos.
Contato: Formulário para enviar mensagens e informações de localização.

Tecnologias Utilizadas:

HTML: Estruturação das páginas.
CSS: Estilização e responsividade.
JavaScript: Interação dinâmica com os usuários.
